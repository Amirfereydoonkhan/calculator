# Calculator — React useReducer Demo

A feature-complete calculator application built in React, using the 
useReducer hook to manage complex operator logic and calculation state.

## 🔗 Live Demo
[View Live App]()

## 🛠 Tech Stack
- React.js
- useReducer (state management)
- JavaScript (ES6+)
- HTML5 / CSS3

## ✨ Features
- Full arithmetic operations (add, subtract, multiply, divide)
- Operator chaining support
- Decimal number handling
- Edge case handling (division by zero, consecutive operations)
- useReducer for predictable state management

## 💡 Why useReducer?
Rather than basic useState, this project uses useReducer to handle 
multi-step calculation logic — demonstrating understanding of React's 
advanced state management patterns in a clean, testable context.

## 🚀 Getting Started

Clone the repository:
git clone https://github.com/Amirfereydoonkhan/calculator.git

Install dependencies:
npm install

Run the development server:
npm start
